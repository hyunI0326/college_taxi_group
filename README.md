# 택시팟

시청, 광화문, 서울역에서 상명대학교로 가는 택시 동승 파티를 만들고 참여하는 iPhone 앱과 웹 앱입니다. 파티장은 지도에서 집결지를 고르고, 탑승 후 총 택시비를 입력해 참여자별 금액을 계산할 수 있습니다.

## iPhone 앱 실행

1. Xcode에서 `ios/TaxiPot.xcodeproj`를 엽니다. iOS 17 이상을 대상으로 하며, 첫 빌드에서 Kakao iOS SDK를 Swift Package Manager로 받습니다.
2. 카카오디벨로퍼스에서 택시팟 앱의 **앱 → 플랫폼 키 → 네이티브 앱 키** 설정에 iOS 번들 ID `com.kimsunghyun.taxipot`을 등록합니다. JavaScript 키와 웹 도메인은 iPhone 앱 설정에 필요하지 않습니다.
3. `cp ios/Local.xcconfig.example ios/Local.xcconfig`를 실행하고 파일의 `KAKAO_NATIVE_APP_KEY`를 발급받은 **네이티브 앱 키**로 바꿉니다. 이미 다른 번들 ID를 등록했다면 같은 파일의 `TAXIPOT_BUNDLE_ID`도 그 값과 똑같이 맞춥니다. 이 파일은 Git에 올라가지 않습니다. 키 없이도 파티 기능은 실행되지만 카카오톡 직접 공유 버튼은 표시되지 않습니다.
4. 같은 Mac에서 `npm start`를 실행한 뒤 iPhone 시뮬레이터에서 앱을 실행합니다. 앱의 기본 서버 주소는 `http://127.0.0.1:3000`입니다.

실제 iPhone이나 다른 사용자의 기기에서 함께 쓰려면 이 저장소의 Node 서버를 HTTPS 주소로 배포하고, 앱 오른쪽 위 **서버** 설정에 그 주소를 입력해야 합니다. 도메인 구매는 필수가 아니지만 공개 HTTPS 주소는 필요합니다. 모든 참여자가 같은 서버를 사용해야 같은 파티와 정산 정보를 봅니다. 현재 서버 데이터는 로컬 JSON 파일에 저장되므로 운영 배포 전 영속 저장소와 사용자 인증을 마련해야 합니다.

iPhone 앱은 MapKit으로 지도와 집결지를 보여 줍니다. 네이티브 앱 키와 공개 HTTPS 서버가 설정되면 카카오톡 파티 공유를 사용할 수 있고, 공유받은 iPhone 앱에서 해당 파티를 엽니다. 일반 공유는 공개 서버의 파티 링크를 포함합니다. 카카오 T 호출·예약과 카카오페이 1/N 요청은 각 앱으로 이동해 사용자가 직접 완료합니다.

## 웹 앱 실행

Node.js 20 이상에서 다음 명령을 실행한 뒤 `http://localhost:3000`을 여세요.

```bash
npm start
```

별도 패키지 설치는 필요 없습니다. 개발 서버는 로컬 컴퓨터에서만 열리며, 파티 데이터는 `data/taxi-pot.json`에 저장됩니다. 여러 사람이 외부에서 쓰려면 서버 배포와 공유 데이터베이스가 필요합니다. 포트는 `PORT` 환경 변수로 변경할 수 있습니다.

```bash
npm test
```

## 현재 범위

- 닉네임으로 파티를 생성하고 참여합니다. 한 택시의 정원은 파티장을 포함해 2~4명입니다.
- 선택한 출발 지역 중심에서 1.2km 안의 집결지를 지도에서 고릅니다.
- 파티장이 총 요금을 입력하면 원 단위 나머지까지 참여 순서대로 나누어 총액과 일치시킵니다.
- 파티장은 승차 정보를 복사하고 [카카오 T 앱](https://www.kakaomobility.com/kakaot/index.html)을 열어 직접 호출·예약할 수 있습니다. 앱에서 출발지, 목적지, 시간과 예약 가능 차량을 다시 선택해야 합니다.
- 택시비를 계산한 뒤 금액을 복사하고 [카카오페이 1/N 정산](https://story.kakaopay.com/05-kakaopay-money/) 화면을 열 수 있습니다. 카카오페이에서 참여자와 금액을 직접 확인하고 요청해야 합니다. 파티원은 정산 요청 내역 화면으로 이동할 수 있습니다.
- 파티 정보는 휴대폰의 공유 메뉴로 공유할 수 있습니다. 공개 서버에 배포하면 공유 링크가 해당 파티를 엽니다. 로컬 실행에서는 다른 기기에서 접속할 수 없어 텍스트만 공유합니다.
- 택시팟이 예약이나 송금을 대신 실행하거나 완료 여부를 확인하지는 않습니다. [카카오모빌리티의 공개 개발자 제품 목록](https://developers.kakaomobility.com/)에서 택시 호출·예약 API는 확인되지 않았습니다. 카카오페이 1/N 링크는 모바일에서 이용하며 택시팟 금액이 자동 입력되지 않습니다. 학교 재학생 인증과 실시간 알림도 포함하지 않습니다. 현재 닉네임은 학교 계정과 연결되지 않으므로 실제 운영 전 인증과 운영 정책이 필요합니다.
- 지도에는 Leaflet과 OpenStreetMap 타일을 사용하므로 지도 표시에는 인터넷 연결이 필요합니다. 지도 데이터 © OpenStreetMap contributors.
